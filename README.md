# Sessão para Windows

Programa da Sessão, a sala privada para assistir junto.

## ⬇️ [Baixar o instalador](https://github.com/edufrohlich-lab/sessao-download/releases/latest/download/Sessao-Instalador.exe)

### Como instalar

1. Abra o arquivo `Sessao-Instalador.exe`.
2. O Windows vai mostrar **"O Windows protegeu o computador"**, porque o programa não tem assinatura digital paga. Clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Pronto. O atalho **Sessão** aparece na área de trabalho e no menu Iniciar.

Entre com o usuário e a senha que você usa no site. Se ainda não tem conta, peça acesso na tela de login.

Requer Windows 10 ou 11 (64 bits).
